# NexusDesk P2P - Deploy su GitHub

Questo progetto è stato generato automaticamente per essere caricato su GitHub.

## 🚀 Come Avviare in Locale

Assicurati di avere Node.js installato. Apri il terminale in questa cartella e lancia:

```bash
npm install
npm run dev
```

## 🌐 Come Caricare su GitHub

Apri il terminale in questa cartella ed esegui i seguenti comandi (sostituendo l'URL con quello del tuo repository vuoto creato su GitHub):

```bash
git init
git add .
git commit -m "Initial commit - NexusDesk P2P Base"
git branch -M main
git remote add origin https://github.com/TUO-UTENTE/TUA-REPO.git
git push -u origin main
```
